# Corpo Event

**Corpo Event** est une application conçue dans le cadre d’un projet de gestion d’événements en entreprise.
Elle permet à différents utilisateurs (organisateurs, participants, etc.) de créer, gérer et suivre des événements de manière fluide et structurée.

Ce dépôt contient les documents de conception du projet : règles de gestion, cas d’utilisation, diagrammes UML (classe et séquence), utiles à la compréhension et à l’évolution de l'application.
